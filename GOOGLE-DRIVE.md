# Синхронизация с Google Диском

Устроено ровно как у «Заказано» — см. [его инструкцию](../zakazano/GOOGLE-DRIVE.md),
там подробно и с картинками в голове. Здесь — только отличия.

## Что приложение делает

* Кладёт в ваш Google Диск один файл — `potracheno-backup.zip`, тот же архив, что и
  «Сохранить в файл». Файл перезаписывается, а не копится.
* Область доступа одна — `drive.file`: приложение видит только собственный файл.
* «Восстановить с Диска» **заменяет** все поездки, траты, долги и фото копией.
* Автовыгрузка раз в сутки — в фоне и только при наличии сети.

## Что нужно сделать один раз

Без этого шага кнопка «Подключить Google Диск» ответит, что приложение
не зарегистрировано в Google Cloud. Всё остальное в приложении работает и так.

Два варианта, выбрать один:

1. **Отдельный проект «Potracheno» в Google Cloud** — на экране согласия будет правильное
   имя «Потрачено». Нужны свои страницы для Branding (home и privacy), по образцу
   `zakazano/site/` — их ещё нет.
2. **Два новых OAuth-клиента в уже настроенном проекте «Заказано»** — быстрее, страницы
   и домен уже есть, но при входе Google покажет имя «Заказано».

В обоих случаях: **APIs & Services → Credentials → Create credentials → OAuth client ID →
Android**, два клиента:

| Клиент | Package name | SHA-1 |
|---|---|---|
| Potracheno | `kz.chaykin.potracheno` | `82:43:83:38:EC:82:D1:CC:4A:85:21:C5:0D:1D:4B:B9:F9:86:F8:59` |
| Potracheno debug | `kz.chaykin.potracheno.debug` | `65:B4:DE:FD:C1:A5:EE:A4:A5:85:5C:37:90:49:4D:3D:32:59:E5:B2` |

Если хватает только установленного APK — достаточно первой строки. Debug-отпечаток
общий с «Заказано»: это стандартный debug-ключ этой машины.

Отпечаток release-ключа берётся так:

```bash
keytool -list -v -keystore potracheno-release.jks -alias potracheno
```

## Проверка на телефоне

**Настройки → Google Диск → Подключить Google Диск** → аккаунт → разрешить.
Дальше «Выгрузить сейчас» и, если нужно, «Выгружать раз в сутки».
